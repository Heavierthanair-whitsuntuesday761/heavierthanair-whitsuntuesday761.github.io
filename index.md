## 📖 How to Use

The interface has three main areas.

**Left sidebar** - Shows report categories and filters. Click a category to see related reports.

**Main panel** - Displays the reports. Each row shows one report with details like date, title, and status.

**Top toolbar** - Contains the search box and action buttons.

### Basic Tasks

**View a report** - Click any row in the main panel. The report details appear on the right side.

**Search reports** - Type a word or number in the search box. The list updates as you type.

**Filter by date** - Use the date picker in the sidebar. Select a start and end date.

**Export reports** - Click the "Export" button in the toolbar. Choose CSV or TXT format. Your browser downloads the file.

**Sort columns** - Click any column header (like "Date" or "Status"). The list sorts by that column.

## ❓ Troubleshooting

### The page does not load

- Make sure you opened `index.html`, not any other file.
- Try a different browser like Chrome or Edge.
- Check that your browser supports JavaScript (most do by default).

### Reports appear empty

- Refresh the page with F5 or Ctrl+R.
- Clear your browser cache: Press Ctrl+Shift+Delete, select "Cached images and files", click "Clear".
- Check the data folder inside the application folder for files.

### Search does not work

- Ensure you typed your search correctly.
- Remove any filters in the sidebar first.
- Try refreshing the page.

### Export fails

- Check your browser download settings. Some browsers block multiple downloads.
- Try exporting fewer rows at once.
- Use the CSV format instead of TXT.

### The tool looks wrong

- Press Ctrl+0 (zero) to reset zoom in your browser.
- Update your browser to the latest version.
- Try the Light theme if Dark theme causes display issues.
